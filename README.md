# Habit Tracker

A clean, modern, and lightweight web application designed to help you build, track, and maintain daily habits effectively.

## Features

- **Simple & Intuitive UI:** Designed for a smooth and distraction-free user experience.
- **Fast Performance:** Built with Vite and React for instant loading and responsive interactions.
- **Local Storage:** Keeps your data safe and private directly in your browser.

## Tech Stack

- **React** (Frontend Library)
- **Vite** (Build Tool & Development Server)
- **CSS / Modern Styling**

## Getting Started

To run this project locally on your machine, follow these simple steps:

1. Clone the repository:
   ```bash
   git clone [https://github.com/ashlafi/habit-tracker.git](https://github.com/ashlafi/habit-tracker.git)
   ```
2. Navigate to the project directory:
   cd habit-tracker
3. Install the dependencies:
   npm install
4. Start the development server:
   npm run dev
5. Open your browser and go to http://localhost:5173 to view the app.
